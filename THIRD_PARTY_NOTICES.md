# Third-party materials

`simulation/OpenABC/` contains the OpenABC 1.0.7 source snapshot used by this
project. Copyright (c) 2023 ZhangGroup-MITChemistry. Its MIT license is preserved
in that directory, along with the original package metadata and README.

MED1 input coordinates originated from the AlphaFold v2.0 model for UniProt
Q15648. The OCT4 input was obtained through the GeneCards POU5F1 proteins entry
(UniProt Q01860). The 200-bp DNA input is the atomistic structure used by the
production package. These structure inputs are provided with their original
identifiers and are not claimed as newly authored structures.

OpenMM, MDAnalysis, MDTraj, NumPy, pandas, SciPy, Matplotlib, and PyMOL retain
their respective upstream licenses. Except for the explicitly vendored
OpenABC snapshot, those dependencies are not redistributed here.

An open-source license for original project code has not yet been selected.
The OpenABC MIT license does not automatically license the surrounding code,
derived research tables, or third-party molecular structures.
